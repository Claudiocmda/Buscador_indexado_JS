Diseñé e implementé un buscador web con sugerencias en tiempo real utilizando un árbol Trie y 
base de datos SQLite, optimizado por popularidad (usando consultas SQL). 

- Construí una API RESTful con Node.js (Express.js) para manejar endpoints de búsqueda , autocompletado, eliminación de streamers y actualización de seguidores. 

- Integré Google Custom Search API para mostrar resultados enriquecidos al seleccionar un streamer. 

- Usé JavaScript para frontend interactivo, con HTML y CSS responsive. 

- Desplegué y probé servicios utilizando Google Cloud Platform y herramientas como Postman. 
  Aprendizajes destacados:diseño de APIs, estructuras de datos (Trie), integración de servicios externos, creación de funciones GET , DELETE y PUT, enfoque escalable, buenas prácticas backend.
